Day-10 Learning Notes :

1. What is JavaScript?

ans. Javascript is a programming language used to make web pages interactive and dynamic.

2. What is the difference between HTML, CSS, and JavaScript?

ans. HTML is used to create the structure of a webpage.
     CSS is used to style the webpage by adding colours, fonts and layouts.
     JavaScript is used to make the webpage interactive and functional.

3. Why do websites use JavaScript?

ans. Websites use JavaScript to provide interactive features and improve the user experience. 
     It allows users to click buttons, submit forms, display messages, create animations and update webpage content.

4. What is the purpose of the script element in HTML?

ans. The script element is used to add JavaScript code to an HTML document.

5. What is the browser console, and how do you open it?

ans. The browser console is a tool available in web browsers that helps developers view JavaScript output, messages and errors. 
     We can open it by pressing F12 on the keyboard and selecting the Console tab in Developer Tools.
