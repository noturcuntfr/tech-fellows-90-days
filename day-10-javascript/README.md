# Day 10 – Introduction to JavaScript

## About This Task

This project is part of my Tech Fellows 90 Days Internship. In this task, I learned the basics of JavaScript and how to connect an external JavaScript file to an HTML page.

## What I Learned

- What JavaScript is and why it is used in web development.
- How to connect an external JavaScript file to HTML.
- How to use `console.log()` to display output.
- How to display text and numbers in the browser console.
- How to perform basic calculations using JavaScript.
- How to create a simple About Me card using console messages.

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. Press `F12` to open Developer Tools.
4. Select the **Console** tab.
5. Refresh the page to see the JavaScript output.
