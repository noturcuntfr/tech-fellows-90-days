# Day-08 My Personal Website

## Project Description

This is a multi-page personal website created using HTML and CSS as part of the Tech Fellows Web Development Internship.

The website contains two pages: Home and About Me.

The Home page introduces me, my interests and learning goals. The About Me page provides information about my educational background, skills, hobbies and contact details.

The main objective of this project is to understand how to connect an external CSS stylesheet to HTML pages and apply basic styling to improve the website's appearance and readability.

## Technologies Used

- HTML5
- CSS3

## Project Features

- Two connected web pages (Home and About Me).
- Personal introduction and profile image.
- Interests and learning goals section.
- Education, skills and hobbies sections.
- Contact section with an email link.
- Navigation links between pages.
- External CSS stylesheet connected to both pages.
- Consistent colours and typography.
- Styled header with a background colour and centered heading.

## CSS Concepts Practiced

- External CSS stylesheet.
- Font family.
- Background colour.
- Text colour.
- Text alignment.
- Font size.
- Line height.
- Borders.
- CSS styling for headers and paragraphs.

## How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS and image files are present.
4. Open `index.html` using Live Server.
5. View the Home page and use the navigation links to visit the About Me page.

## Readability Improvements

1. Used a readable font family and appropriate paragraph font size.
2. Added a suitable background and text colour to improve readability.
