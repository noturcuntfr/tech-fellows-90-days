# 🚀 Day 10 — QR Code Component

## 📌 Project Overview

This project is part of the **Tech Fellows 90-Day Full-Stack Development Internship**.

For Day 10, I completed a frontend design challenge from Frontend Mentor. The task was to recreate a QR Code Component using HTML and CSS while following the provided design reference and style guide.

The main goal was to practise frontend development, understand CSS styling, and create a responsive webpage.

## 🎯 Project Objectives

- Recreate the Frontend Mentor QR Code Component design.
- Build the webpage using HTML.
- Style the component using CSS.
- Match the given colors, spacing, layout, and typography.
- Make the design responsive for mobile and desktop screens.
- Upload the project to GitHub.
- Deploy the website using Vercel.

## 🛠️ Technologies Used

- **HTML5** — To create the webpage structure.
- **CSS3** — To style the QR code card and page layout.
- **GitHub** — For source code management.
- **Vercel** — For website deployment.

## ✨ Features

- Clean and simple QR code component.
- Centered white card layout.
- QR code image with rounded corners.
- Light blue background.
- Styled heading and description.
- Responsive layout for different screen sizes.
- Frontend Mentor challenge attribution.
