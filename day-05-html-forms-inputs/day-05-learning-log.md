# Day 05 - Learning Log

## What I Built
I created a student registration demo form using HTML.
It includes personal information, course selection,
study mode, learning goals and a confirmation checkbox.

## Two Validation Checks I Tested
1. I tested the required fields by submitting an empty form.
2. I tested email format and the minimum/maximum age limits.

## One Bug I Fixed
I temporarily changed a label's for attribute so it
did not match the input id. I corrected the mismatch.

## Why Client-Side Validation Is Not Enough
Client-side validation can be bypassed, so a real
application must also validate submitted information
on the server.

## One Improvement for Later
I would like to improve the form's appearance using CSS
and make it more responsive.
