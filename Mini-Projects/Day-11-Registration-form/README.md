# Student Registration Form 💗

A modern, pastel pink student registration form built with HTML & CSS.
Part of Tech Fellows | 90-Day Full Stack Internship - Day 11 Mini Project.

## ✨ Features

- Modern pastel pink theme using CSS variables
- Fully responsive form - works on mobile & desktop
- Styled inputs with focus ring effect
- Pill-style gender selection
- Required field indicator (*) in pink-red
- Hint text for Name, Phone & Password
- Center-aligned heading & subtitle
- Clean, modern card design with soft pink shadow

## 🛠️ Tech Used

- HTML5
- CSS3 (External Stylesheet, CSS Variables, Flexbox)
- No JavaScript / No Framework

## 📝 Form Fields

- Full Name *
- Email *
- Phone Number *
- Date of Birth *
- Gender *
- Select Course *
- Address
- Password *

## 🎨 Color Theme

| Use | Color | Code |
| :--- | :--- | :--- |
| Primary | Pastel Dark Pink | `#e07a9a` |
| Accent | Pastel Light Pink | `#ffafc7` |
| Background | Soft Pink | `#fde8ed` |
| Card | White Pink | `#fff9fb` |
| Text | Dark Pink-Brown | `#4a2c34` |

60-30-10 Rule:
- 60% - Background Pink
- 30% - Card White-Pink
- 10% - Primary Pink (Button, Heading)

## 🚀 How To Run

1. Download / Clone this repo
2. Open folder `registration-form`
3. Double click `index.html`
   OR
   Right click -> Open with Live Server in VS Code

No installation needed.
