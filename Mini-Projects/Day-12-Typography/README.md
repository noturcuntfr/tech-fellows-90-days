# Student Registration Form - Day 12 Mini Project

## About
Day 12 Mini Project from Tech Fellows 90-Day Full Stack Internship.
Student Registration Form with pastel pink theme and professional typography.

## Day 12 Updates
- Google Fonts added: Poppins for headings, Inter for body
- Fonts saved in CSS variables
- All font sizes in `rem` only, no `px`
- Body: `1rem` size, line-height `1.6`
- H1: `2rem`, bold, centered
- Labels: `0.95rem`, bold
- Inputs use `font: inherit`
- Button: UPPERCASE, bold
- Hint: `0.85rem`, Placeholder: italic
- Intro text: max `65ch`, centered
- Login link in L-V-H-F-A order

## Tech Used
- HTML5
- CSS3
- Google Fonts (Poppins + Inter)
