# Day-07 My Personal Website

## Project Description

This is a two-page personal website created using HTML5 as part of the Tech Fellows Web Development Internship.

The purpose of this project is to create a personal website that introduces me and presents my interests, educational background, skills, hobbies and contact information.

The website consists of two pages: Home and About Me. Both pages are connected through navigation links.

## Technologies Used

- HTML5

## Project Pages

### 1. Home Page (index.html)

The Home page includes:

- Welcome heading and personal introduction.
- Profile photograph with alternative text.
- List of personal interests and learning goals.
- Navigation links to Home and About Me.
- A section to explore the About Me page.

### 2. About Me Page (about.html)

The About Me page includes:

- Personal background and education information.
- List of technical skills.
- List of hobbies and interests.
- Contact section with an email link.
- Navigation links to the Home page.

## HTML Concepts Practiced

- Basic HTML document structure.
- Headings and paragraphs.
- Images and alternative text.
- Ordered and unordered lists.
- Anchor tags and hyperlinks.
- Navigation links.
- Semantic HTML elements such as:
  - `<header>`
  - `<nav>`
  - `<main>`
  - `<section>`
  - `<footer>`
- Relative file paths.
- Email links using `mailto:`.
- Same-page navigation using section IDs.

## How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Make sure both HTML files and the images folder are present.
4. Open `index.html` in a web browser.
5. Use the navigation links to move between the Home and About Me pages.
