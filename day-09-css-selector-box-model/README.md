# My Personal Website

## Project Description

This is a personal website created using HTML and CSS as part of the Tech Fellows Web Development Internship.

The website contains two pages: Home and About Me.

The Home page introduces me, my interests and learning goals. The About Me page provides information about my educational background, skills, hobbies and contact details.

## Technologies Used

- HTML5
- CSS3

## Features

- Two linked web pages (Home and About Me).
- Personal introduction and profile image.
- Education, skills and hobbies sections.
- Navigation links between pages.
- Modern lavender and white design.
- Styled content sections with borders and rounded corners.

## CSS Concepts Used

- Element selectors
- Class selectors
- ID selectors
- Margin and padding
- Borders and border radius
- CSS Box Model
- Reusable card class

## Instructions to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all HTML, CSS and image files are present.
4. Open `index.html` using Live Server.
5. Use the navigation links to visit the About Me page.
