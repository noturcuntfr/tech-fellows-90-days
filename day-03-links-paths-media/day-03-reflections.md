
# Day 03 - Learning Reflection

### 1. Which path was easiest to get wrong, and why?

The image path was easiest to get wrong because
the folder name and image filename must match exactly.

### 2. How did you confirm a link points to the right destination?

I clicked each link in the browser and checked
whether it opened the correct page or section.

### 3. What is the difference between a page link and a fragment link?

A page link opens another HTML page, such as about.html.

A fragment link jumps to a particular section on the
same page or another page using its ID.

### 4. What would you improve before showing this mini-site to another student?

I would improve the page design using CSS, add better
spacing and make the website responsive.

### 5. Debugging experience

Problem: The profile image did not load.

Cause: I accidentally misspelled the image filename.

Solution: I corrected the filename in the src attribute
and refreshed the browser.
