# Day 02 - Learning Reflectio

## 1. Difference between HTML tag, element and attribute

An HTML tag is the keyword written inside angle brackets,
such as <h1> or <p>.

An HTML element includes the opening tag, content and
closing tag.

An attribute provides additional information about an
element, such as href in an anchor tag or src in an image tag.

## 2. When should you use an ordered list?

An ordered list is used when items need to follow a
particular sequence or order, such as steps or instructions.

An unordered list is used when the order of items does
not matter.

## 3. Why does an informative image need alt text?

Alt text describes the meaning or purpose of an image.
It helps people using screen readers understand the image
and provides useful information if the image cannot load.

## 4. What happened when I broke and fixed an internal link?

When I changed a section ID without updating the matching
navigation link, the link stopped jumping to the correct section.

I fixed it by restoring the original ID so that the href
and section ID matched again.

## 5. Debugging experience
